# Changelog — SochoYhaPe

All notable changes to the SochoYhaPe platform are documented here.

## [v1.0.0-final] - 2026-09-05 (Phase 7 Complete)

### Added
- **Landing Page Polish**: Updated hero headline to *"Stop Searching. Start Finding It Here."* and tagline to *"SochoYhaPe helps engineering students find, analyze and successfully build the right final-year project."*.
- **Auth & Onboarding Routes**: Built functional `/sign-in` and `/get-started` interfaces with email/password and OAuth triggers.
- **Documentation Suite**: Added `docs/DATASET_DOCUMENTATION.md`, `docs/SETUP_GUIDE.md`, `docs/TROUBLESHOOTING.md`, updated all architectural docs, and updated root `README.md`.
- **QA Verification Pass**: Verified zero-error compilation across all 11 application routes.

## [v0.6.0] - 2026-09-05 (Phase 6 Complete)
- **Saved Projects**: Bookmarking functionality with toast notification feedback.
- **Project Matrix Comparison**: Side-by-side comparison of 2–3 projects with Gemini AI trade-off analysis.
- **Project Roadmap**: Interactive 8-stage progress tracker with note persistence.
- **GitHub Finder**: Live GitHub REST API integration for open-source reference codebases.
- **Team Skill Matcher**: Skill coverage analyzer for multi-student project groups.
- **Student Dashboard**: Aggregated student workspace workspace.

## [v0.5.0] - 2026-09-05 (Phase 5 Complete)
- **Idea Feasibility Analyzer**: AI proposal risk & feasibility breakdown.
- **AI Senior Mentor Chat**: Interactive Q&A for project details.
- **Viva Preparation**: External examiner simulation mode.

## [v0.4.0] - 2026-09-05 (Phase 4 Complete)
- **Gemini 2.5 Flash SDK Integration**: Secure server functions for AI recommendation synthesis.

## [v0.3.0] - 2026-09-05 (Phase 3 Complete)
