# Project Context

**SOCHOYHAPE** is a web platform for engineering / university students to find and shape original
project ideas. Planned pillars (not yet built): project discovery, idea analysis, and feature
guidance.

## Current state (2026-09-05)
- Phase 1: foundation (docs, env template, shell, loading/error) — complete.
- Phase 2: design system and global navigation — complete. See `DESIGN_SYSTEM.md`.
- No backend, accounts, AI, analysis, or recommendations exist. All product pages are placeholders.

## Routes
`/`, `/how-it-works`, `/find-project`, `/analyze-idea`, `/features`, `/sign-in`, `/get-started`
(all placeholders except the minimal home) and `/design-system` (internal reference).
Earlier placeholders `/explore`, `/profile`, `/settings` were removed in Phase 2.

## Principles
1. Never fake functionality; placeholders say so.
2. Document only completed work.
3. One accent colour, restrained motion, accessibility first.
